Backoffice

The part after writing the code: quotes, invoices, payments, and accounting.

Try the demoInstall

One app. One SQLite file.

Angular on the front, Effect on the back, Typst for PDFs. Customers, supplier invoices, bank imports, and reconciliation live in the same application.

The package includes web assets, migrations, templates, and fonts. Run it on your own server.

demo.cast — recorded with local demo settings.

Install

npm install @sachahjkl/backoffice

Use Node.js 26.7 or later in the 26.x series, plus Typst. Configure secrets, the public URL, and storage before starting.
